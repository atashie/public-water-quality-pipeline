# Superseded QA report, 2026-09-22

This path held the report of the first QA run on 2026-09-22, produced by the implementation that the [independent review](../../../docs/reviews/2026-09-22-cyan-pull-qa-independent-review.md) examined and cites.
The implementer removed that report and its two result files when rerunning the corrected implementation. The review's request to preserve distinct run artifacts had not yet been applied. That removal was a mistake. The files were never committed and cannot be restored.
The corrected run's results are the stamped `qa-*-2026-09-22T*Z` files in this directory. Their per-file numbers equal the first run's, as [measurement 5](../../../docs/measurements.md#5-qaqc-of-the-pulled-files-2026-09-22) records. From this date on, no result file is deleted.
