What this page shows and does not show

  • Shows: every native 300 m code inside a review window for any pulled week or day, the code under the cursor, the composition of the window and of the whole canvas, the QA verdicts, and the provenance of the files and of this page.
  • Does not show: anything inside a lake polygon, any average, any value's correctness, any cause of missing data, or any file not pulled. Coverage percentages include the canvas outside the region.
  • Display choice: colors are assigned in the browser from the code. Land and no data can be hidden to see the water classes alone.
